# Methodology

## Core principles

- Fraud is treated as an imbalanced classification and decision problem.
- Accuracy will not be used as the primary success metric.
- Historical features must be leakage-safe.
- Evaluation will use a time-based holdout.
- Threshold selection will include fraud value, false positives, manual-review
  capacity and explicitly documented assumed operating costs.
- Rules, ML and a hybrid approach will be compared.
- Model explanations must be derived from actual model features.
