# Project Plan

## Phase 1 — Data foundation
Raw ingestion, typed staging, data quality, date validation, missingness.

## Phase 2 — Cleaning and fraud profiling
Parse complex fields, investigate anomalies, currencies, outliers and fraud distributions.

## Phase 3 — SQL behavioral features
Customer/card/device/IP velocity, previous transaction behavior, rolling spend and novelty features.

## Phase 4 — Network analytics
Card-device-IP-merchant relationships and suspicious shared-identifier clusters.

## Phase 5 — Modeling
Logistic Regression baseline, tree models, class imbalance handling and chronological evaluation.

## Phase 6 — Business decisioning
Risk score, thresholds, fraud value capture, false-positive cost and review capacity.

## Phase 7 — Explainability
Global and transaction-level SHAP explanations.

## Phase 8 — Products
Power BI management dashboard and Streamlit fraud investigation application.

## Phase 9 — Monitoring
Score drift, feature drift, fraud rate and model-performance monitoring.

## Phase 10 — Portfolio
README, architecture, screenshots, metrics, resume bullets and interview story.
